     1→# Project Worklog — Tabla de Verbos (Modern Spanish Verb Trainer)
     2→
     3→## Project Vision
     4→Rebuild the classic "tabladeverbos" Spanish verb chart app as a modern, editorial-feeling web app with:
     5→1. **Tables mode** (classical): searchable verb picker + subject, fill-in conjugation chart (23 forms), check answers with per-cell feedback, reveal/reference mode.
     6→2. **Practice mode** (new): one-by-one random questions — (a) conjugation (random verb+subject+tense), (b) translation ES→EN, (c) translation EN→ES. Timed challenge (user-set timer, max correct/accuracy) or Infinite mode. Streaks, accuracy stats, session history persisted in SQLite via Prisma.
     7→
     8→## Architecture
     9→- Next.js 16 App Router, single route `/` (client SPA with two mode tabs).
    10→- Conjugation engine ported from original JS to TypeScript at `src/lib/conjugator/` (pure logic, shared by API + client).
    11→- APIs (all under `/api`, no server actions): `/api/conjugate` (POST), `/api/check` (POST), `/api/practice/question` (POST), `/api/verbs` (GET), `/api/sessions` (GET/POST).
    12→- Prisma SQLite: `PracticeSession` model.
    13→- Design: warm paper/editorial aesthetic — Fraunces (display) + Inter (body) + IBM Plex Mono (labels), Spanish-brick-red primary, cream background, no blue/indigo. Light+dark themes. Framer Motion animations.
